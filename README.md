# 🚨 Suwon-si Real Estate Fraud (Jeonse) Risk Analysis & Prediction
**"Data-Driven Protection: AI 기반 수원시 전세사기 위험 매물 통합 관제 플랫폼"**

> **2025 데이터 분석 프로젝트**  
> 10만 건 이상의 실거래가 데이터와 GPT-3.5 API를 결합하여, 시민들을 전세사기 위협으로부터 보호하는 인텔리전트 대시보드입니다.

<br>

## 🌟 Project Key Highlights
*   **Real-time Risk Mapping:** 수원시 전역의 실거래 데이터를 분석하여 전세가율 80% 이상의 위험 매물을 지도상에 시각화
*   **AI Insight Generation:** GPT-3.5 Turbo 모델을 연동하여, 선택한 매물의 위험 요인을 부동산 전문가의 시각으로 즉시 요약 분석
*   **Statistical Precision:** 통계적 기법을 활용한 전세가율 분포 분석 및 이상치(Outlier) 탐지

<br>

## 🔍 Core Technologies & Intelligence

### 🤖 Generative AI Integration
*   **Model:** `GPT-3.5-Turbo`
*   **Context:** 부동산 전문가 프롬프트 엔지니어링을 적용하여 단순 수치를 넘어선 **'위험 시나리오'** 해석 (e.g., 전세가율 과다, 계약 유형의 불확실성 등)

### 📊 Data Engineering & Analytics
*   **Preprocessing:** `Pandas`를 이용한 10만 건 이상의 하우징 데이터 클렌징 및 위경도 정밀 좌표계 최적화
*   **Spatial Analysis:** `Folium` 및 `MarkerCluster`를 활용한 고밀도 지리 정보 시각화 로직 구현
*   **Dynamic Visuals:** `Plotly Express`를 이용한 인터랙티브 전세가율 분포 히스토그램 구축

## 🏠 System Architecture
1.  **Data Ingestion:** 수원시 전세/매매 실거래 데이터 수집 및 전세가율 산출
2.  **Risk Engine:** 전세가율 및 계약 유형 기반의 위험 지표 계산 (Applied Statistics Logic)
3.  **Visualization:** Streamlit 기반의 프리미엄 UI/UX 대시보드 표출
4.  **AI Analysis:** 클릭 이벤트 발생 시 OpenAI API를 통한 실시간 리스크 리포트 생성
